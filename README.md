# BOOTH 髪型検索 (booth-hair-search)

アバターのスクリーンショットや髪型画像から、BOOTH の似た髪型商品を探すツール。
画像を直接照合するのではなく、**髪型の形状タグ（長さ・結い方・質感など）を中間表現**に
挟んで照合します。色タグは改変で最も変わるため使いません。

> ⚠️ 完全自動で「1件を当てる」ツールではありません。**候補を出して人が選ぶ**設計です。
> 自動抽出タグは手で修正・追加でき、そこで精度が上がります。

## できること

- 画像アップロード → 髪型タグを自動抽出 → **日本語（カナ）で手修正** → 類似検索
- 結果を 10 件ずつページ送り／並び替え（類似度・類似＋スキ・類似＋新着）
- 各候補から BOOTH 商品ページへリンク

## 仕組み（概要）

1. WD Tagger v3（ONNX Runtime, CPU）で画像から髪形状タグを抽出
2. タグ確信度ベクトルのコサイン類似度（IDF 重み付き）で照合
3. 候補を表示し、BOOTH へ送客

推論はすべて **CPU ローカル**で完結します（GPU 不要）。

## 使い方（開発版）

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # Windows
python src/step7_ui.py                                    # → http://127.0.0.1:7860
```

（配布パッケージ版では、ダウンロードして実行するだけでセットアップ不要になる予定です。）

## データの取り扱い（重要）

本ツールは BOOTH の公開情報を「独自の検索・レコメンド」に活用します。BOOTH の
ガイドライン（2025-10 改定、常識的な範囲のスクレイピングを許容）に沿うよう、
以下を方針とします。

- **BOOTH の商品画像（サムネイル）を配布物に同梱・再配布しません。**
  サムネイルは表示時に、各利用者の端末が BOOTH から直接取得し、手元にキャッシュします
  （ブラウザで商品ページを開くのと同じ、閲覧のための取得です）。
- 配布・保持するのは **検索用のタグベクトルと商品 URL のみ**です。
- **商品ファイル本体（zip / unitypackage 等）は取得も配布もしません。**
- クロールは**直列・低速・キャッシュ利用**で、サーバーに過負荷をかけません
  （`src/booth_client.py` に実装）。取得元 URL には連絡先を明記します。
- 検索結果は必ず **BOOTH 商品ページへのリンク**を伴い、購入は BOOTH で行われます
  （＝出品者・BOOTH への送客）。
