アバターのスクショ等から BOOTH の似た髪型商品を探すツール（完全ローカル・ノーセットアップ）。

変更点はコミット履歴 / マージ済みPRを参照してください（リリース後にこの本文へ追記してもOK）。

## 使い方
1. `booth-hair-search-win-x64.zip` をダウンロードして解凍
2. **書き込み可能な場所**（Downloads / Desktop 等。Program Files は不可）に置く
3. `booth-hair-search.exe` をダブルクリック → ブラウザで開く画面から検索

- 画像アップ → ①タグ抽出 → 気になる特徴をカナで手修正 → ②検索
- サムネは表示時に BOOTH から取得（このアプリに商品画像は同梱していません）
- 検索DB・日本語辞書は起動時に自動更新されます

## 注意
- Windows x64 向け。初回起動は少し時間がかかります
- ネット接続が必要（サムネ表示・商品ページリンク・起動時のDB更新のため）
